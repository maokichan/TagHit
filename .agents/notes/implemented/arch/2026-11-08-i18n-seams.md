# 决策：i18n 接缝——vue-i18n 骨架与插件文案自译契约

Status: implemented

## Problem

界面文案全部硬编码中文：渲染层约 110 个文件（按钮/提示语/命令面板标题）、host 侧错误信息、插件贡献文案（manifest 标题与设置项、命令 title、toast）。D9 当时的"i18n 非目标"只说不做，未立接缝。现在要为国际化留缝：第二语言只做英语，不为更多语言预建模；`docs/` 与 README 纯中文维护，不纳入 i18n。

## Decision

- **选型 vue-i18n**（v11，composition 模式 + `globalInjection`）：zh-CN 为底语言 + en，`fallbackLocale: 'zh-CN'`；语言包每语言一个 JSON，缺 key 回落中文（英文包不完整时回退安全）。
- **范围 = 运行时用户可见文案**：渲染层界面、host 产出的用户可见错误、插件贡献文案。文档不在内。
- **locale 状态仿 theme 走 ui store**（内存态，持久化不在契约 v0）；AppConfig 声明字段与默认值（`zh-CN`）。
- **D9 修订**：错误码信封原样——渲染层"按 code 取短句"在后续文案批次改为按当前语言取句，host 侧 message 退化为调试细节；本批不动错误映射。
- **插件贡献文案 = 插件自译（D51）**：manifest 的 `title` / `description` / `settings[].label` / `options[].label` 允许字符串或语言映射（`{ "zh": …, "en": … }`），纯字符串透传（三方插件零影响）；
渲染层 `resolveLocalized`（`lib/localized.ts` 纯函数）统一解析：映射取当前语言、缺失回落首值。解析时点：manifest 装载（`manifestOf`）与 peek 行为装载时、命令 title 注册时快照、toast/confirm 调用时。宿主 `validateManifest` 同步放宽为两形态。
- **机检随行（check-i18n，D50/D51 随行件）**：`frontend/scripts/check-i18n.mjs` 零依赖双探针——键对账（各 locale 对 zh-CN 基底；
vue-i18n 缺 key 告警是 dev 条件编译、打包态被剥掉，出厂静默回落只有机器对账能堵）+ 中文残留基线（`frontend/scripts/i18n-residue-baseline.json`，键 = 文件::文本段、与行号无关）。
语义分层：警告态 `check:i18n` / 门控态 `check:i18n:strict`（键缺失或基线外新增即挡）挂 `npm run ci`（pre-push）与 `npm run pack` 打包前置。基线只收不涨：`--update-baseline` 只删已消失条目，新增须 `--accept-new` 有意识收纳。
跟踪面 = 渲染层 UI 源码（排除 `__tests__` / i18n 语言包 / styleguide / `console.*` 行 / 注释行）；host 中文 = 调试细节、docs 中文 = 政策、插件中文 = 插件资产，均不在跟踪面。
repoGuard 同步豁免两处文案事实镜像（i18n/locales/ + 残留基线——UI 文案可能合法含路径示例，绝对路径红线约束的是 agent 笔下的共享文档）；豁免已集中单点登记 `ops/exemptions.json`（path + guards + reason，各守卫按名取用，取代此前 trash/ 在三脚本各写一份的散落硬编码）。
- **翻译工作流（开发者定形，随抽取批执行）**：抽取（本体，结构改动）→ 子代理低强度翻译（机械执行，TERMS.md 约束）→ 审批（术语一致性 / 最短必要 / 插值复数）→ 拿不准升级开发者。术语表 = `frontend/src/renderer/src/i18n/TERMS.md`（工艺随行件，与语言包同址，不进 GLOSSARY——那是开发侧一词一义的职能）；
文案删减权随抽取批（§二.4：交互自明的删、说明进 hover、死路留最短行动句，删改清单随批次报告）。语言自名（中文 / English）存语言包且两语言同值，不硬编码源码。
- **存量落地事实**：全量抽取完成（语言包 490 键 zh+en 同构，渲染层源码非注释中文仅剩 1 处基线白名单 = shortcuts 启动日志的多行 console 模板字面量）；错误码取短句改按当前语言（shared/api.ts `errors.*`，D9 接缝闭合）；设置页语言切换控件已落（外观区，接 `ui.setLocale`）；
余项 = en 长文案溢出走查（TODO 主线 9）+ locale 持久化随 config 迁宿主。

## Alternatives considered

- **自造迷你 t() 函数**：输在四项——切语言全树响应式刷新、插值与英文复数规则、缺 key 回退与告警、locale 包按需加载，全部要自己补齐且无人维护；vue-i18n 是 Vue 官方生态标准件。petite-vue-i18n（API 子集）体积更小，但 Electron 对体积不敏感，取完整版。
- **渲染层集中翻译插件文案**（插件给 key、壳语言包放译文）：只对官方插件可行，第三方插件的 key 无法预先翻译，契约不通用。
- **本批做全量文案抽取**：机械迁移量大，与骨架耦合会拖长验证回路；先立缝再分批。

## Consequences

- 所得：接缝一次立齐（实例、状态、manifest 契约、宿主校验），后续批次只是填 key 与迁移文案；manifest 契约现在定死，避免将来改格式。
- 代价：渲染层多一个运行时依赖；存量文案未迁移期间 en 包长期不全会回落中文；命令标题注册时快照，切语言后需重新装载插件才刷新；host 侧 message 仍产中文（定位为调试细节）。
