# 决策：i18n 接缝——vue-i18n 骨架与插件文案自译契约

Status: implemented

## Problem

界面文案全部硬编码中文：渲染层约 110 个文件（按钮/提示语/命令面板标题）、host 侧错误信息、插件贡献文案（manifest 标题与设置项、命令 title、toast）。D9 当时的"i18n 非目标"只说不做，未立接缝。现在要为国际化留缝：第二语言只做英语，不为更多语言预建模；`docs/` 与 README 纯中文维护，不纳入 i18n。

## Decision

- **选型 vue-i18n**（v11，composition 模式 + `globalInjection`）：zh-CN 为底语言 + en，`fallbackLocale: 'zh-CN'`；语言包每语言一个 JSON，缺 key 回落中文（英文包不完整时回退安全）。
- **范围 = 运行时用户可见文案**：渲染层界面、host 产出的用户可见错误、插件贡献文案。文档不在内。
- **locale 状态仿 theme 走 ui store**（内存态，持久化不在契约 v0）；AppConfig 声明字段与默认值（`zh-CN`）。
- **D9 修订**：错误码信封原样——渲染层"按 code 取短句"在后续文案批次改为按当前语言取句，host 侧 message 退化为调试细节；本批不动错误映射。
- **插件贡献文案 = 插件自译（D51）**：manifest 的 `title` / `description` / `settings[].label` / `options[].label` 允许字符串或语言映射（`{ "zh": …, "en": … }`），纯字符串透传（三方插件零影响）；渲染层 `resolveLocalized`（`lib/localized.ts` 纯函数）统一解析：映射取当前语言、缺失回落首值。解析时点：manifest 装载（`manifestOf`）与 peek 行为装载时、命令 title 注册时快照、toast/confirm 调用时。宿主 `validateManifest` 同步放宽为两形态。
- 存量约 1000 处文案抽取、错误码按语言取句、设置页语言切换 UI 留待后续批次。

## Alternatives considered

- **自造迷你 t() 函数**：输在四项——切语言全树响应式刷新、插值与英文复数规则、缺 key 回退与告警、locale 包按需加载，全部要自己补齐且无人维护；vue-i18n 是 Vue 官方生态标准件。petite-vue-i18n（API 子集）体积更小，但 Electron 对体积不敏感，取完整版。
- **渲染层集中翻译插件文案**（插件给 key、壳语言包放译文）：只对官方插件可行，第三方插件的 key 无法预先翻译，契约不通用。
- **本批做全量文案抽取**：机械迁移量大，与骨架耦合会拖长验证回路；先立缝再分批。

## Consequences

- 所得：接缝一次立齐（实例、状态、manifest 契约、宿主校验），后续批次只是填 key 与迁移文案；manifest 契约现在定死，避免将来改格式。
- 代价：渲染层多一个运行时依赖；存量文案未迁移期间 en 包长期不全会回落中文；命令标题注册时快照，切语言后需重新装载插件才刷新；host 侧 message 仍产中文（定位为调试细节）。
