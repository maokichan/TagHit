# 决策：壳版式——底板 + 卡片 · 全直角

Status: implemented

## Problem

壳的版式没有统一模型：顶栏/状态栏/面板/内容区各自带底色与接缝，区域边界靠 1px 缝线承担；圆角三级制作为现行制度在组件间流转，但圆角梯度不承载任何信息分职；条目卡、面板卡、区域框的区分手段混用明度、边框与圆角，"什么在分层"说不清——版式走查暴露 P6 边框反模式（靠边框区分层次）。逐处修补修不出一致性，需要一次定形。整套裁决的现行事实住[架构活体文档](../../../../docs/ARCHITECTURE.md)版式词汇条与[风格基线](../../../../docs/STYLE.md)，论证层由本篇承载。

## Decision

**底板 + 卡片**：窗口 = 一张底板（`--bg` 最深），顶栏与状态栏直接坐在底板上（去自身底色与接缝）；**左卡 = 活动栏 + 弹出面板同一张卡**（`--bg-elev` + 边框，距窗缘留距；图标栏与面板之间发丝线分节，仅面板展开时绘制防双线）；**内容区留在底板上**（不做成卡），四周留白（距左卡、距右缘、距顶栏都有距离）。
区域分层 = **明度差 + 距离**，替代 1px 区域接缝（P6 边框分职改写；工作台槽位/底板是同一模型在页面内的应用，见[架构活体文档](../../../../docs/ARCHITECTURE.md) §二工作台条）。

**全直角（气质决策）**：全界面不用圆角，圆角三级制废止；`rounded-*` 入 STYLE §6 禁区，确需圆角走 STYLE §5 例外清单；存量内联圆角已随壳重构全量清扫，圆角机检已启用（[frontend/scripts/check-style.mjs](../../../../frontend/scripts/check-style.mjs)）。

连带落定：搜索与扫描入口上顶栏（= 坐底板）——「全局搜索的入口归属」待裁决项由此落地为顶栏常驻入口，作用域口径（当前工作区 vs 全库）另立裁决；非工作区标签页搜索置灰；「共 N 项」计数迁状态栏（活动工作区门控防跨标签残留）。
样式表治理同轮完成：`chip--solid`/`chip--excluded` 死条目撤除（其消费面"筛选 chip"已被搜索框词元形态取代），`.btn`/`.icon-btn` 与 `.row-actions`/`.card-actions` 共享形态合并。

## Alternatives considered

- **圆角三级制**（此前的现行制度）：输在圆角梯度不承载信息分职——区域分层已由明度差 + 距离承担，三级圆角只剩装饰性梯度，与直角气质相抵。废止而非收紧，`rounded-*` 直接入禁区；存量分批清扫后由机检接管。
- **1px 区域接缝**（此前的区域边界手段）：输在接缝线沿窗口满屏铺线，线是全局噪音；明度差 + 距离同样能分平面且不画线——同一处规则同时治理了工作台首版"兄弟之间 1px 缝线"的方案（缝线退化为缝隙里的拖柄）。
- **内容区做成卡**：输在条目卡与底板的明度差会被卡底吃掉——内容区自己成为卡后，条目卡只能靠边框与底板区分，正是 P6 反模式；内容区留底板，条目卡以明度差自然浮出。

## Consequences

所得：版式有了单一模型（底板 + 卡片 + 明度差分层），新界面元素按模型落位不再逐处裁量；P6 边框反模式有了机械化的替代答案；样式表死条目清零、冗余形态合并减重；全局搜索入口的归属落定（顶栏常驻）。

代价：`rounded-*` 禁区要求新增圆角必须走 STYLE §5 例外清单，自由度受限是有意为之；壳重构是版式的落地载体（当时 TODO 主线 1，已落地销账）；全局搜索的作用域口径仍未裁决；真圆角需求若出现要过例外清单，例外的裁定权在人。
