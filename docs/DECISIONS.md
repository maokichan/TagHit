# TagHit 决策基线（DECISIONS）

分层、裁决与范围。概念见 GLOSSARY。

## 分层

```
渲染层 / 用户输入
   │
应用层（用例：流程编排，调领域规则与端口）     ← 规划中
   │
领域层（实体类型 + 纯规则，无存储、无 IO）     ← src/domain
   │
端口（接口）──── 适配器（实现：SQLite/文件/…） ← 规划中
```

依赖只向内。行为在应用层；存储等实现位于领域层之外。

## 裁决

- 条目 item：全局唯一身份，不属任何工作区；去重是扫描行为（应用层）
- 工作区：索引容器；不拥有条目；条目可见性派生自来源路径树节点状态（节点只管其直接条目）
- 挂载：条目 × 标签（条目级）；取回条目返回全部标签
- 声明：工作区 × 标签的读取端投影事实，投影行为在应用层
- 标签关联：领域层只承认"标签间存在有向关联"，不解义；应用层按 is-a 组织（方向约定 子→父）
- 作品：独立实体 + 有序成员 + 空条目标签锚点
- 组：全局扁平容器、标签可多属；语义在应用层
- 元数据：核心事实 + EAV 长尾，键注册表约束
- 渲染层：只认 uri，字节经主进程闸门
- 全局搜索：对全部工作区

## 领域层（src/domain）

`types.ts`（实体与关系记录）· `rules.ts`（纯规则：命名、标签关联不变量、有向图可达/成环判定）· `errors.ts`

## 应用层用例（规划中）

收录扫描（路径遍历 + 条目级扫描）· 打标/卸标（is-a 上溯）· 浏览与声明投影 · 检索 · 组与作品维护 · 删除级联 · 事件

## 端口与适配器（规划中）

存储端口（先内存后 SQLite）；文件系统；ID/时钟注入。

## 假设（未否决即生效）

| # | 假设 | 默认值 |
|---|---|---|
| D1 | tag 描述 | 属 tag 实体 |
| D2 | ID | UUIDv4 字符串（适配器注入） |
| D3 | 声明 | workspace × tag 集合是事实，仅读取端投影用 |
| D4 | 领域层 | 同步纯函数；异步只在边界 |
| D5 | 搜索 | 应用层查询用例 |
| D6 | 事件 | 只保留有真实订阅者的事件 |
