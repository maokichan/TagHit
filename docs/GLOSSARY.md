# TagHit 词表（GLOSSARY）

业务词汇的单一事实源。分层见 DECISIONS。

## 实体

| 实体 | 定义 |
|---|---|
| 条目 item | 内容单元；全局唯一身份，不属任何工作区。素材条目有来源（sourceUri = 归一化绝对路径）；空条目·锚无来源，承接作品标签 |
| 工作区 workspace | 组织内容的索引容器：只与来源路径交互，不拥有条目 |
| 标签 tag | 全局唯一命名的标记原子；可与其他标签存在有向关联 |
| 作品 collection | 有序容器：组织多个条目；自身标签挂在空条目标签锚点上 |
| 组 group | 组织标签的扁平容器 |
| 路径节点 pathNode | 扫描在某来源根下发现的目录（含来源根本身 = 根节点）；身份 = 工作区 × 目录路径；带节点状态；只管直接位于其中的条目，不涉及子节点或根节点 |

## 关系

| 关系 | 端点 | 说明 |
|---|---|---|
| 标签关联 | tag → tag | 有向；语义由使用方组织 |
| 挂载 | 条目 × 标签 | 条目级，无工作区上下文 |
| 声明 | 工作区 × 标签 | 读取端投影的事实：未声明的标签不交付该工作区 |
| 成员 | 作品 → 条目 | 有序 |
| 成员 | 组 → 标签 | 无序 |
| 来源根 | 工作区 × 目录路径 | 配置行：工作区拥有其来源根集合（不含条目）；各来源根递归索引 |
| 退役根 | 工作区 × 目录路径 + 卸载时间 | 来源根的**卸载记录**：卸载只删来源根行与其节点树（条目不受影响），记录是那些条目的可寻址凭据，供**来源根组件**（全页）决定去留（清理条目 / 重新挂载）；挂载同一路径即清除 |
| 脱根条目 | 条目 | 有来源但**没有任何来源根覆盖**的条目：退役根之下的（有记录）或无记录的历史残留；不进任何工作区视图，只能经**来源根组件**（全页）处置 |

## 属性

- tag：name（全局唯一）、description
- item：来源 sourceUri、来源类型、内容哈希、大小、文件修改时间、状态；元数据 = 核心事实 + EAV 长尾；previewUri（派生缩略图缓存路径，{userData}/thumbnails，按内容哈希共享）
- collection：名称、成员顺序
- 节点状态 nodeState：included / excluded —— 仅作用于该节点的直接条目，不级联

## 工作区 ↔ 条目（派生）

- 条目的直接节点**不落库**：归属以 sourceUri 的父目录 == 某路径节点的 dirPath 派生。
- **派生在存储查询内执行**（D19）：可见性作为查询条件 `directNodeStateIn` 翻译为 `EXISTS(路径节点 且 state=included)`，
  `ORDER BY / LIMIT / total` 一律作用于结果集——不在应用层"取回来再筛"（否则条目数随排序变化）。
  路径纯规则单一来源 = `src/domain/paths.ts`（SQL 译文与之等价，由校准 s35 双跑比对）。
- 节点 excluded 只隐藏其**直接**条目；子树整体批量设置 = 应用层批量入口（setSubtreeState，单事务逐节点），领域语义仍为逐节点、不级联。
- **浏览范围**（只看某节点）是渲染层视图状态（下推为 `underDirPath` 路径段范围），**不是**可见性：退出即恢复，不写库。
- **卸载来源根**留退役根记录（D20）：条目仍全局存在，但脱离全部来源根、不进任何工作区视图；其去留在**来源根组件的全页**处置（清理条目 / 重新挂载）——窄面板只给计数与入口。
- 本文件的词是**领域词**；功能组件名（渲染层词）是另一套，见 ARCHITECTURE「官方功能组件名录」——组件名取领域对象名（如「来源根」），不另造别名。

## 分层归属

- 领域层：以上实体/关系行记录的类型与纯规则（`src/domain`，无存储、无 IO）；路径规则 `domain/paths.ts`
- 应用层：声明投影、来源根挂/卸与退役根记录、脱根条目读取与清理、扫描创建与维护路径节点、可见性派生条件的组装、删除级联（已落地）；事件（规划中）
- 渲染层：只认 uri，字节经主进程闸门
- 适配器：条件对象的翻译（含路径派生 SQL 译文，等价性由校准保证）
