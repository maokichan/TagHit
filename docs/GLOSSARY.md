# TagHit 词表（GLOSSARY）

业务词汇的单一事实源。分层见 DECISIONS。

## 实体

| 实体 | 定义 |
|---|---|
| 条目 item | 内容单元；全局唯一身份，不属任何工作区。素材条目有来源；空条目·锚无来源，承接作品标签 |
| 工作区 workspace | 组织内容的索引容器：只与来源路径交互，不拥有条目 |
| 标签 tag | 全局唯一命名的标记原子；可与其他标签存在有向关联 |
| 作品 collection | 有序容器：组织多个条目；自身标签挂在空条目标签锚点上 |
| 组 group | 组织标签的扁平容器（无继承/修饰语义） |

## 关系

| 关系 | 端点 | 说明 |
|---|---|---|
| 标签关联 | tag → tag | 有向；语义由使用方组织（v1 应用层按 is-a：子→父） |
| 挂载 | 条目 × 标签 | 条目级，无工作区上下文 |
| 声明 | 工作区 × 标签 | 读取端投影的事实：未声明的标签不交付该工作区 |
| 成员 | 作品 → 条目 | 有序 |
| 成员 | 组 → 标签 | 无序 |

## 属性

- tag：name（全局唯一）、description
- item：来源、来源类型、内容哈希、大小、文件修改时间、状态；元数据 = 核心事实 + EAV 长尾
- collection：名称、成员顺序

## 分层归属

- 领域层：以上实体与关系的不变量与派生规则（`src/domain/rules.ts`，纯函数）
- 应用层（规划中）：声明投影、is-a 语义与上溯、组语义、两阶段扫描、删除级联、事件
- 渲染层：只认 uri，字节经主进程闸门

## 预留

来源类型扩展 · 修饰（应用层对标签关联的另一种语义组织）· 作品嵌套/多归属 · 保存搜索 · 全文搜索 · 导入导出 · AI 标签 · C-S 团队协作
