# 渲染层风格基线（STYLE）

> 归属：**frontend 专属**（渲染层）。权威范围：`frontend/src/renderer/**` + [frontend/src/renderer/src/styles/globals.css](../frontend/src/renderer/src/styles/globals.css)。
> **不约束**后端核心（领域/端口/应用/适配器）——风格是渲染层的事。
> 本文是渲染层开发的**准则**：新组件先读本文，再动代码。冲突裁决顺序：本文 > [docs/ARCHITECTURE.md](ARCHITECTURE.md) > 组件内注释。
> 方法取自 TuRead 项目的同名样式实践：**标准样式表 + 组件只挂类名 + 禁区机器可断言**。

## 1. 风格定性

TagHit 是**内容管理工具**：界面是内容的容器，视觉为浏览与打标服务——紧凑、暗色为默认、琥珀单强调。
不做排印化的"文字即界面"（那是阅读器的身份）；图标是合法语汇（lucide），但**图标不替代文字承担命名**。

## 2. 六条原则（冲突时按序裁决）

- **P1 样式表单点**：颜色/字号/圆角/组件词汇只定义在 `styles/globals.css`；组件**只挂类名**。
  样式表里没有的形态，先去样式表加类，**不许在组件里发明一次性样式**（机检 §6）。
- **P2 字号阶梯**：`11`（说明与次要）· `12`（正文与控件）· `13`（输入与强调）·
  阅读面（标签主页）：页标题 `16`、文档节标题 `16/14/13`、文档正文 `13`；`14+` 其余仅空态主句与
  起始页品牌字（34）。白名单外禁止（机检）。
- **P3 反馈靠边框，阴影只给浮层**：卡片/行/按钮的悬浮反馈 = 边框变亮（`--border-hover`）；
  阴影只允许出现在浮层（弹层/下拉/拖拽预览）与详情页媒体主图上。暗色下卡片阴影不可见还引发重绘。
- **P4 交互自解释**：优秀的交互不需要引导赘文（界面文案纪律，见根层入口文档红线）；说明进 hover 提示，死路才给指引，
  且给最短行动句。
- **P5 动效克制**：只允许过渡类的色变/透明度、按压 `0.97` 缩放、扫描 spinner 与停靠面板开合的宽度过渡（`.panel-slide`——用户做了开合动作，动画是动作的回应）；无关键帧入场动画、无弹跳缩放、无位移入场。`prefers-reduced-motion` 下去掉缩放与宽度过渡，保留色变/透明度。
- **P6 层级语法**（版面的"先后"怎么表达；语言取自 VS Code 的拆解，`npm run style` 有现场样张）：
  - **明度分平面（底板 + 卡片）**：窗口 = 一张**底板**（`--bg`，最深）；顶栏与状态栏直接坐在底板上，
    区域卡（左卡 = 活动栏 + 弹出面板）与条目卡浮在底板上，区域分层 = **明度差（`--bg` < `--bg-elev` < `--bg-hover`）＋ 距离**（卡片距窗缘留距、内容四周留白），不画区域接缝——
    眼读明度差快过读边框，**底板最深、卡片最浅，档距须一眼可辨**（暗色下明度差弱，
    卡片自身轮廓由边框兜底，见下条）；
  - **边框分职**：边框回答"对象到哪里结束"，不负责"区域之间怎么分"（那是底板模型的事）——
    **卡片与控件的自身轮廓**（左卡、条目卡、输入、浮层）= 1px `--border` **全强度**，全直角；
    **对象之内分节**用 `.divider`（`--border-soft`，比交互边框低一档）；
    **surface 内禁同重嵌套盒**——分节 = 节头 + 发丝线，不 `.panel` 套 `.panel`（盒中盒 = 两套语法说同一层级，扁平感的根源）；
    详情页工作台槽位（D41）同此模型：槽位卡浮在工作台底板上，卡片间缝隙即底板透出，不画缝线；
  - **宽度即身份**：区域宽度由内容性质决定（事实行窄、正文宽、媒体占主角），不设默认等宽；
  - **一页一重心**：每个页面只有一个高对比视觉重心（详情页 = 媒体主图，主页 = 正文，网格 = 缩略图阵列）；
    其余内容降一档——阅读态的标签词元去框化（`.chip--text`），形态即状态（不可改就不长可改的样子）；
  - **节拍折叠**：常显骨架（节头 + 少量关键事实），长尾信息进可折叠节（`.section-head`），
    不整栏全量常驻；节间用统一节拍（节头 → 内容 → 大间距），节拍一致层次自然出现。

## 3. Token（唯一来源 = `globals.css`）

组件内**禁止写死** hex / rgb / rgba（机检）——一律走 `var(--*)`：

| 组 | token | 用途 |
|---|---|---|
| 背景层级 | `--bg / --bg-elev / --bg-hover` | 底板 / 卡片 / 悬停（明度阶梯 = P6 的平面语言：底板最深、卡片最浅，档距一眼可辨） |
| 边框 | `--border / --border-hover / --border-soft` | **对象接缝**（全强度）/ 悬浮反馈 / 发丝分隔（仅 surface 内分节） |
| 文字 | `--fg / --fg-dim` | 正文 / 次要 |
| 强调 | `--accent / --accent-soft` | 选中与主动作，**只强调一次** |
| 状态 | `--danger / --warn / --ok` | 语义状态，不做装饰；饱和度与中性阶同钥（哑光），accent 是全主题唯一高饱和 |
| 遮罩 | `--overlay-dim / --overlay-soft` | 弹层压暗 / 轻遮罩（黑度不随主题） |
| 几何 | `--panel-width / --page-max-width` | 停靠面板宽 / 全页版心（壳级单点） |

**直角（气质决策，论证见决策笔记「壳版式——底板 + 卡片 · 全直角」）**：全界面**不用圆角**——轮廓感来自边框与明度差，不靠圆角软化；
`rounded-*` 是禁区（§6，机检），确需圆角的形态（如圆形媒体元素）走 §5 例外清单。
**间距**：4 的倍数（Tailwind 刻度 1/2/3/4…）。

## 4. 组件类名录（新组件从这里拼装）

| 类 | 形态 | 用在哪 |
|---|---|---|
| `.panel` | 卡片（bg-elev + 边框，直角） | 卡片、设置分区 |
| `.panel-label` | 小节标签（11px 灰，正常字距——中文不做 uppercase/拉距） | 停靠面板/右栏小节标题 |
| `.divider` | 发丝分隔线（比交互边框低一档，横用） | surface 内分节（P6） |
| `.section-head` | 可折叠节头（11px 灰 + 展开箭头；`data-open` 管箭头朝向，悬停亮） | 渐进披露的长尾分节 |
| `.btn` / `.btn-primary` | 按钮（灰字 → 悬停亮，按压 0.97）/ 琥珀实心主按钮 | 一切按钮 |
| `.icon-btn` | 纯图标按钮（无底色，尺寸由调用方给；按压 0.95） | 行内清除、移出 |
| `.input` | 输入框（focus 琥珀边；禁用降透明度） | 一切输入 |
| `.kbd` | 键位帽 | 快捷键展示 |
| `.chip` / `--action` / `--on` / `--text` | 标签：静态只读 / 可点（未挂载）/ 挂载态（琥珀 soft）/ **去框词元（阅读态纯文本，悬停亮）**——筛选与排除以搜索框词元形态存在，不走 chip | 标签、候选、筛选入口 |
| `.error-note` | 失败提示条（danger 12% 底，✕ 钮由组件自带） | 一切错误横幅 |
| `.data-row` / `.row-actions` | 数据表行：整行底色反馈 + 行尾操作按需显形（hover / 键盘焦点，隐藏态不命中指针） | 池总表等管理表 |
| `.cell-edit` | 可编辑文本单元格（静默灰字，悬停亮 + 虚线下划线，focus 琥珀环） | 管理表的就地编辑列 |
| `.group-card` / `.card-actions` | 卡片行尾操作按需显形（同一套规则） | 组卡 |
| `.segmented` / `.segment` | 分段控件（互斥视图切换；选中段上浮一档） | 统计 |
| `.bar-track` / `.bar-fill` | 关系条带（宽度走 `:style` 的几何数据，外观在这里） | 统计可视化 |
| `.doc` | 渲染文档形态族（markdown-it 输出：标题/列表/代码/引用；html 关闭即转义） | 标签主页正文 |
| `.panel-slide` | 停靠面板开合的宽度过渡（200ms ease-out，reduced-motion 跳变） | SurfaceHost 停靠面板 |
| `.wb-tabstrip` / `.wb-tab` / `--on` | 工作台槽位 tab 栈：小号标签（激活 = 顶部 accent 细条 + 上浮一档底色） | 详情页工作台（D39）槽位 |
| `.wb-seam` | 缝隙里的拖柄：底板从卡片间 6px 缝隙透出（明度差即分界），拖柄静默透明、悬停/拖拽亮 accent 线 | 工作台分割树（D41）枝内兄弟 |
| `.wb-edge[data-on]` | 缘落点区（拖拽中出现的分割热区）：命中染 accent-soft + accent 描边 | 工作台拖 tab 到槽缘分割 |
| `.marquee-box` | 框选矩形（几何走 `:style`，外观在这里） | ItemGrid 框选 |
| `.filmstrip-box` / `.filmstrip` | 预览条：size 容器查询自适应——横容器横排、竖容器竖排，每格 `clamp(3.25rem, 50cq×, 8rem)` 随可用区域伸缩 | 详情页预览条 |
| `.wordmark` | 起始页品牌字（字距是排印决策，唯一出现处） | StartScreen |
| `.popup-fade-*` | 浮层显隐过渡（只做透明度，P5 无位移/缩放入场） | 搜索弹出面板等浮层 |
| `.drag-region` / `.no-drag` | 无边框窗口拖拽区 | TabBar/窗口控制键/顶栏弹出面板 |

**几何与样式之分**：动态几何（缩放 transform、框选 left/top/width/height、瀑布流定位）是**数据**，
走 `:style` 绑定，不进样式表；样式表管"长什么样"，不管"在哪"。

## 5. 例外清单（此外加边框/阴影/颜色先改本文）

| # | 例外 | 理由 |
|---|---|---|
| ① | 详情页媒体主图的 `shadow-lg` | 全质量预览浮在页面上，需要与背景分层 |
| ② | 下拉候选/弹层/轻通知的边框与阴影 | 浮层例外（P3），遮罩走 `--overlay-*` |
| ③ | 挂载/选中态的琥珀 soft（`.chip--on`）与实心主按钮 | 选中态需要强于静态一档（`--on` 与 `--action` 是两个词汇） |
| ④ | `:style` 几何绑定 | 见 §4 末——数据不是样式 |

## 6. 禁区（机器可断言 = `npm --prefix frontend run check:style`）

1. 组件内写死颜色（`#hex` / `rgb(` / `rgba(`）——只允许在 `globals.css`。
2. `bg-black/*`——遮罩黑度走 `--overlay-*`。
3. 白名单外字号（现阶段即 `text-[10px]` 及以下）。
4. `uppercase` / `tracking-*` 类——中文界面不做大写；字距只允许样式表定义（`.wordmark`）。
5. 静态内联 `style="`——几何走 `:style`。
6. `rounded-*` 圆角类——全直角（§3），机检已启用（D44 落地时存量 44 处一并清零）。

新增禁区：先改本文，再去 [frontend/scripts/check-style.mjs](../frontend/scripts/check-style.mjs) 加一条。

## 7. 新组件检查表（8 条）

1. 颜色是否全部走 token？（§3，机检兜底）
2. 字号是否在阶梯内？（§2 P2，机检兜底）
3. 这个形态样式表里有吗？有 → 挂类名；没有 → 先加类再用，**不发明一次性样式**（§4）。
4. 悬浮反馈是边框变亮吗？阴影是否只用在浮层？（§2 P3）
5. 可点元素有没有按压反馈，且 `prefers-reduced-motion` 下会取消缩放？（§2 P5）
6. 区域层级是用明度/节拍/发丝线表达的吗？有没有 surface 内的盒中盒？这个页面只有一个视觉重心吗？（§2 P6）
7. 文案是否做到了"交互自解释"？说明是否只进了 hover？（§2 P4 / CONTEXT §四.4）
8. 空态与失败是否可见、是否给了最短行动句？（§2 P4）
