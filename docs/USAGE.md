# TagHit 使用指南

> 记录时间：2026-08-23（随项目日期）
> 面向用户：TagHit 的日常使用说明（非开发文档；开发见 [ARCHITECTURE.md](ARCHITECTURE.md) 与 [API.md](API.md)）

---

## 一、界面总览

```
┌──────────────────────────────────────────────────────────────┐
│ 标签栏（主页 / 工作区 / 条目 / 设置，可拖拽、可关闭）            │
├────────┬─────────────────────────────────────────┬───────────┤
│ 左活动栏│                                         │ 右活动栏   │
│ 路径/标签│          主内容区（路由视图）            │ 媒体信息/  │
│ /显示   │  主页 · 工作区网格 · 条目详情 · 设置       │ 插件      │
├────────┴─────────────────────────────────────────┴───────────┤
│ 状态栏（扫描进度 / 最近扫描结果 / 插件数量）                    │
└──────────────────────────────────────────────────────────────┘
```

- **主页**：只在"没有多余标签页"或点击 `+` 新建标签页时出现（主页单例：已有主页则激活，不重复新建）。鼠标侧键后退不会跳回主页。
- **工作区标签**：主页点击工作区卡片 = 当前标签变为该工作区。
- **条目标签**：网格双击卡片 / 全局搜索点击结果 = 新开条目标签页，不占用当前标签。
- **设置标签**：右上角设置图标开/关。

## 二、工作区与扫描

### 创建工作区
主页 → 工作区栏右侧 **新建** → 输入名称 → 回车创建。

### 配置扫描路径
工作区标签页 → 左侧活动栏 **路径** 面板 → 添加目录（原生目录选择器）→ 自动触发扫描。
- 目录支持"递归包含子目录"。
- 移除路径会将该路径下的条目从工作区**脱离**（条目与标签保留在全局库中，重加路径即恢复）。
- 扫描按钮在搜索栏最右侧；进度显示在底部状态栏。

### 扫描语义（重要）
- **新增/变更**：增量扫描按"大小 + 修改时间"跳过未变文件，内容哈希（xxHash64，前 64KB）用于去重与变更检测。
- **缺失**：目录还在但文件消失 → 条目标记为"缺失"（卡片半透明 + 角标）。
- **脱离**：路径被移除 / 目录整体消失 → 条目从工作区脱离（不删除全局条目与标签）。

## 三、标签体系（核心）

### 概念
- **全局标签池**：标签定义全局唯一（所有工作区共享）。
- **工作区声明**：某标签必须被某工作区"声明"后，才能在该工作区**可见 / 可搜索 / 可挂载**。声明只改变可见性；取消声明不删除已有挂载，重新声明即恢复。
- 创建工作区标签 = 创建全局标签 + 自动声明到该工作区。

### 打标（给条目贴标签）
1. 进入条目详情（工作区网格**双击**卡片，或全局搜索点击结果）。
2. 右侧"标签"区：显示当前工作区已声明的标签；点击 `+标签名` 即挂载，再点取消。
3. 只可挂载**当前工作区已声明**的标签（未声明会被拒绝）。

### 按标签筛选（= 标签搜索）
打标后如何找到这些条目：
1. 回到工作区，左侧活动栏 **标签** 面板——**点击任意已声明标签 = 筛选该标签的条目**（再点取消；可多选，多标签取交集）。
2. 选中的标签高亮为实心；搜索栏下方会显示当前筛选状态（`筛选：#标签`），可单独或全部清除。
3. 工作区网格中卡片上的标签 chip 也可点击筛选。

### 标签管理
- **工作区标签面板**：声明/取消声明、新建标签（自动声明到当前工作区）、从全局池声明。
- **设置页 → 统一标签管理**：全局池分组展示、每工作区声明/取消、层级（父子）维护（防环）。

## 四、搜索

### 工作区内（网格过滤）
- **关键词**：搜索栏过滤文件名。
- **标签**：左侧标签面板点击筛选（见上）。
- **媒体类型 / 排序 / 布局**：左侧活动栏 **显示** 面板——媒体类型（图片/视频/音频/文档）、排序（最近更新/名称/大小/修改时间/添加时间/类型 × 升降序）、布局（瀑布流/网格/列表）、卡片标题显隐。

### 全局搜索（开始界面）
主页中央搜索框，支持 DSL：

```
@标签1 @标签2 type:image >2024-01-01 <2024-12-31 workspace:1 关键词
```

- `@标签`：条目在**任一工作区**拥有该标签即命中（全局搜索不要求声明）。
- `type:`：image / video / audio / document。
- `>日期 <日期`：按文件修改时间范围。
- `workspace:N`：限定工作区。
- 结果点击 = 新开条目标签页，详情页自动带上工作区上下文。

## 五、条目详情与预览

- **图片**：按原始分辨率显示，超出可视区自动等比缩小（**靠左自适应，无黑色容器背景**）。
- **视频 / 音频**：内联播放器（音频居中窄条）。
- **文本**（txt / md / json / 代码等）：内联文本预览（≤ 2MB）。
- **无可预览内容**（3D 模型、Adobe 工程文件等专业格式）：显示 **"在系统中打开"** 按钮——用系统关联应用打开（组织归 TagHit，打开归系统）。
- 右侧信息列：媒体信息（大小/修改时间/路径 + 元数据 EAV：宽高、时长、编码等）+ 标签挂载。
- 网格缩略图：懒生成（图片 canvas 缩放 / 视频抓帧），不直出原图。

---

## 六、设置页

- **外观**：主题（深色/浅色/跟随系统）、布局默认、卡片标题显隐、工作区封面显隐。
- **媒体**：ffmpeg 路径（ffprobe 推导）、缩略图参数、扫描排除规则。
- **工作区管理**：重命名 / 删除 / 路径管理。
- **统一标签管理**：全局池 + 各工作区声明 + 层级。

---

## 七、插件

- 插件目录：`resources/plugins`（内置）与 `{userData}/plugins`（用户安装，同名覆盖内置），重启应用生效。
- 右侧活动栏 **插件** 面板：查看已加载插件、状态、工具列表。
- 插件能力按 `plugin.json` 的 `permissions` 声明（fs / network / shell），详见 [PLUGIN-ARCH.md](PLUGIN-ARCH.md)。

## 八、数据位置

| 数据 | 位置 |
|---|---|
| 数据库 | `{userData}/taghit.db`（SQLite WAL） |
| 缩略图缓存 | `{userData}/thumbnails/` |
| 工作区封面 | `{userData}/covers/` |
| 配置文件 | `{userData}/config.json` |
| 日志 | `{userData}/logs/taghit.log`（1MB 滚动，保留 5 份） |

`{userData}` 在 Windows 为 `%APPDATA%/taghit`，macOS 为 `~/Library/Application Support/taghit`。

## 九、键盘与鼠标

| 操作 | 效果 |
|---|---|
| 双击条目卡片 | 打开详情（新条目标签） |
| 单击条目卡片 | 选中（右侧媒体信息面板展示元数据） |
| 鼠标侧键返回 | 在标签之间后退，**不会跳回主页**（主页仅按需出现） |
| 标签栏 `+` | 新建标签页 = 激活/新建主页（主页单例） |
| 拖拽标签 / 活动栏图标 | 调整顺序（活动栏顺序持久化） |
