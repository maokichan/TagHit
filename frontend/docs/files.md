# 文件管理组件（files）

> 渲染层侧行为规格；操作闸门与路径段匹配的机制同源性见 `docs/ARCHITECTURE.md`（字节闸门条），
> 领域重定基规则见 `src/AGENTS.md`。

## 应用内操作直改库（免扫）

- **移动/改名**在同一事务内按同一条重定基规则（domain rebasePath）改写条目来源与节点行：
  保 id 保标签、title 随文件名、excluded 意图随行、目的地祖先节点链补齐——可见性 = 直接父节点
  存在且 included（查询时派生），新目录没有节点行会让条目当场脱视图，故祖先链必须补齐。
- **删除 = 条目记录级联清除**（应用内删除即删除，不标缺失——标签是可再生信息，文件本身在
  系统回收站可寻回，反悔后重扫按新条目收录）。
- **删除进系统回收站**；不可恢复删除不进用例面。

## 操作闸门

- 移动/删除只收**来源根之下**的路径（路径段匹配，与字节闸门同一份实现、同一规则）；
  越界只留日志。
- 来源根目录本身不进移动/删除面。
- **原生目录选择是唯一对话框端点**（移动目标经目录选择器取，不手输路径）。
