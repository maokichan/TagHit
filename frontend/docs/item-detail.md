# 条目详情（item detail：骨架 + 工作台）

> 机制与词汇（顺序上下文三条纪律、工作台分割树模型）见 `docs/ARCHITECTURE.md` §二；打标动作
> 收口（编辑模式/速打）见 `docs/tags.md`。本文收**行为规格与数据面细节**。

## 顺序窗口数据面（itemWindow）

- 形状：定位锚条目 + 前后各 N 条（**N 缺省 6、钳制 1..24**）；命中集合与浏览查询同解；
  **只认素材条目**（锚条目不进浏览序列；锚不在序列内 → `index = -1`，读宽松）。
- 实现 = "全量 id 扫描 + 窗口内 hydrate"（定位本就要求位置）；大库要更省再走 keyset
  （排序键 + id 复合游标，见根 `TODO.md`）。
- **窗口返回 `from`**：`index` 是锚在**序列**里的位置，`hits` 是"锚 ± radius"的**切片**——
  调用方必须用 `切片位置 = index − from`，拿 index 直接索引 hits 会跳张、越界；
  该算术收口在纯函数 `features/windowNav.ts`（Vitest 直跑）。

## 翻页与顺序上下文

- **四路翻页键**：`←`/`→` 与 `PgUp`/`PgDn`（媒体元素聚焦时方向键让位原生控件，否则视频没法
  用键盘定位）+ 主图两侧按钮 + 底部**前后各 6 张预览条**（点击即跳），位置显示"第 N / 总数"。
- 翻页实现为**命令**：启动时注册，实现在详情页挂载期登记到渲染层翻页桥，未挂详情页时空操作；
  路由 replace 不写历史（侧键返回回到来处的网格/搜索）。
- **上下文兜底链**：标签项 `context` → 路由 query → 再用标签项的工作区补缺口；**绝不退成
  "跨工作区全库"**（`workspaceId = null` = 整库素材，静默退去会让翻页在整库里乱跳；
  热重载/旧会话残留的标签项可能没有 `context` 字段，而用例缺省恰好是跨工作区）。
- **搜索入口的顺序上下文取"产出这批结果的关键词"**，不是输入框实时值：输入框有 250ms 防抖，
  改完字立刻点旧结果时两者会错位，条目就不在原序列里。
- **loose 回落**：锚不在固化视图序列（搜索词已变/跨工作区打开/无节点归属/不在「只看某节点」
  范围）→ 用例退到**全部素材**（保留排序方向）并回报 `loose`，进度显示"（已按全部素材）"，
  **不给死胡同**；连全部素材里都没有（锚 = 非内容条目）才真的没有序列。
- 配套：**切换工作区视图时清掉多选集与选中项**——选中项属于上一个视图，留着会让信息面板拿
  别的库的条目去开详情。

## 预览与渲染细节

- 图片缩放、解码完成后换图**不闪白**；预览条容器查询自适应（竖容器竖排/每格钳制伸缩）。
- 版式（信息栏折叠节/阅读态去框词元）按风格基线 P6 执行（`docs/STYLE.md`）。

## 渲染层可测性纪律（本组件是样板）

- 纯规则单列纯函数（路由映射 `features/routes.ts`、窗口算术 `features/windowNav.ts`），
  router 副作用（激活标签、push/replace）留在 `features/tabs.ts`——**纯模块不 import router**，
  测试才不会把整张 .vue 组件图拉进来（Vitest 只跑不需要 DOM 的纯逻辑）。
