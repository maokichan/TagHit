# 来源根组件（paths）

> 渲染层侧行为规格；领域模型与派生语义见词表（[docs/GLOSSARY.md](../../docs/GLOSSARY.md)），宿主与扫描事实见
> [docs/ARCHITECTURE.md](../../docs/ARCHITECTURE.md) §一。全页/窄面板分工（批量与去留处置归全页）是名录级通则，不在此复读。

## 树交互

- 每根一个目录树容器，树形由路径前缀派生；可见性逐节点切换、**不级联**（词表：节点状态只作用
  该节点直接条目）。
- **Shift+点击 = 子树批量入口**（面板就地形态）；右键节点行补语义直白的子树批量动作——
  与面板行内动作同语义同用例（「只看此目录」走浏览范围这一视图状态，「隐藏/显示子树」走
  单事务批量），不新增数据面。

## 生命周期：卸载与退役根

- **卸载留凭据**：卸载来源根 = 删来源根行与其节点树（**条目不动**），并落一行**退役根**记录
  （路径 + 时间）；条目数按前缀实时统计、不冗余存储。
- **挂载同一路径即清除记录**：挂载 = 恢复归属，节点树随重扫重建。
- 卸载删整棵节点树是明文语义，不改——条目可寻址性由退役根记录保证。

## 脱根条目（有来源但无任何来源根覆盖）

- 分两段报告：**退役根之下的**（有记录，给精确路径/时间/条目数）与**无记录的历史残留**
  （按父目录聚合；若日后要"一次挂回原根"，需在退役记录机制之外补扫描历史或让用户标记归因）。
- 判定用否定式路径段条件下沉存储，不把全库条目捞进内存。
- **清理安全性由构造保证**：候选集恒为"当前脱根条目"，传来源根路径也删不到在根下的条目；
  磁盘文件不动。
- 去留处置（清理条目 / 重新挂载）在**全页**；窄面板只做就地操作（名录通则）。
