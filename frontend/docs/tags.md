# 标签能力（tags）

> 渲染层侧行为规格；领域词（挂载/声明/组/退役根）见 [docs/GLOSSARY.md](../../docs/GLOSSARY.md)，标签比较键等
> 领域判定纪律见 [src/AGENTS.md](../../src/AGENTS.md)。

## TagProfile：有类型的主页文档

- **tag 是一级实体，有自己的阅读面**。TagProfile = **有类型文档**：schemaVersion 管演进，
  加内容形态 = 加字段 + 升版本；**只渲染不查询的长尾进文档，核心事实留在 Tag 一等列**
  （要被排序/搜索/聚合的都不进文档）；EAV 不为此提前动工——某字段要可查询时再从文档提为真列。
- 形状唯一校验 = `domain/rules.normalizeTagProfile`（版本/容量/链接守门，宿主写入口与存储读
  出口共用同一份，坏文档暴露为 INVALID）；独立端点 `tags.getProfile`/`setProfile`
  （null = 清除）；列表/查询投影**不携带**文档；deleteTag 随行级联（s32 双跑对齐）。

## 标签主页（阅读面）

- 词条版面：左栏**事实条**（描述/挂载/声明统计 = 池级全局口径；组）+ 工作区口径**共现邻居**
  （按打开瞬间固化的工作区上下文，无上下文不显示）+ 右侧**正文列**。
- 正文 Markdown：html 关闭即转义；`[[标签名]]` 解析为站内标签主页链接、解析不到保持原样
  （已知边界：代码块内同形文本也会被替换，罕见且无害）；外链经宿主 `setWindowOpenHandler`
  转系统浏览器（应用内不弹新窗口）。
- **入口 = 详情页 chip 双击**（"双击 = 打开"是应用既有词汇；编辑模式下双击的两次 toggle 互相
  抵消无净变化，**不加单击去抖**——打标是高频动作，不为低频手势牺牲高频手感）。

## 详情页编辑模式（打标动作的收口）

- **Ctrl+E 双向切换**（allowInEditable）：阅读态标签区**静态**防误触（相册翻页是高频动作，
  误改是最贵的手感事故），修改类动作（点 chip 打标/摘除、搜标签、数字键速打）只在编辑模式。
- 模式态挂**条目标签项**：路由视图按 fullPath 重挂、翻页即重建组件，只有标签项对象贯穿浏览
  会话——翻页保持模式、新开详情回阅读态。
- 生效范围事实 `detailTaggable`/`detailEditing` 入调用上下文，命令面板与键位表如实标注。

## 检索语法与打标候选

- `withoutAnyTag` = 挂**任一**给定标签即排除；空数组/缺省 = 不排除（空集否定式恒真，
  与路径否定条件同款语义）；排除语法贯通契约/适配器/搜索词法。
- **搜索词法只认已声明标签名**：`-x` 仅当 x 是已声明标签才成为排除，文件名连字符不误伤；
  标签筛选默认即必须含有（与语义一致），`+` 不引入。
- 打标候选按**共现相关性**排序。

## 标签全页（池管理）

- 池总表 / 页内新建 / 描述内联编辑 / 组卡 / 批选就地切换 / 数字速打 / 共现互斥统计。
- **统计口径 = 工作区成员**；形态：共现条 = 相对强度、互斥条 = 两侧条目量（不伪造共现值）；
  数据面 = `tags.stats` / `tags.pairStats`（s32 校准）。
