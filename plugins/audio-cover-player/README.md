# audio-cover-player（黑胶播放器插件）

> 首个三方形态插件：音频封面 + 播放器，预览槽 / 命令 / 设置声明制 / 自开页四个面的首个消费方，
> 已可 zip 分发（打包与装载机制见 `plugins/AGENTS.md`）。本文收**本插件的呈现与行为规格**。

## 全局播放与生命周期（标签页与资源挂钩）

- 播放是壳级全局能力（渲染层应用级单例，机制见 `docs/ARCHITECTURE.md` §二「全局播放引擎」）：
  切标签页/返回网格**不停播**，页面组件只是遥控器。
- **本标签的资源被替换（翻页/预览条点选）或关闭正在播放其音频的标签 = 停播**——标签是资源的
  会话容器，资源变了会话即终结（引擎暂停、进度保留）。

## 黑胶形态

- **整个盘（含封面圆）是一个旋转体**：封面圆裁填盘心（盘径 34%）随盘一起转，盘面纹理半透明
  叠加（亮暗主题通用）。
- 转动 = **引擎有声音在响**（不区分本条目）；起转渐快/暂停自然减速（rAF 角速度缓动）；
  `prefers-reduced-motion` 恒停；高频控制零动画（图标即切）、按压 `0.95`。
- **盘尺寸 clamp [180px, 420px]**（低于下限的替代显示模式待定，见本目录 `TODO.md`）。

## 播放器页（单页自组织）

- **单页左右分区**：左黑胶 + 传输控制、右歌词；container query 窄槽上下堆叠；左右分区不画线。
- 传输控制：±15s 快退/快进 · 播放/暂停 · 单曲循环 · 静音+音量条。
- **自开页「正在播放」**：全局播放的常驻控制面（黑胶 + 传输 + 歌词跟随当前播放，无播放给空态）。

## 歌词

- **只读文件事实**：同名 `.lrc` 伴生优先、内嵌歌词标签次之（`item.readAudioMeta` 通道；
  不进文本预览白名单）——数据层产物跟宿主能力走、呈现层（解析与呈现）跟插件走。
- 解析：行首多时间戳、元数据标签丢弃、无轴行坠尾；活动行同步高亮；无词右列给"正在播放"排版
  而非空句。内嵌路径机制支持但未经真机验证（HOUSE 素材零内嵌词，见 `TODO.md`）。
